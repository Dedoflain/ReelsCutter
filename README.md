# Reels Cutter

Android-приложение: режет длинное видео на клипы 9:16 (под Reels/Shorts/TikTok) и вшивает русские субтитры. Всё работает на телефоне, без интернета.

## Как получить APK

**Вариант 1 — без компьютера (GitHub):**
1. Создайте репозиторий на github.com и загрузите в него все файлы из этого архива (включая папку `.github`).
2. Вкладка **Actions** → **Build APK** → дождитесь зелёной галочки (~5–8 мин).
3. Откройте запуск → **Artifacts** → скачайте `ReelsCutter-apk`, распакуйте, установите `app-debug.apk`.
   Модель распознавания речи скачивается автоматически во время сборки.

**Вариант 2 — Android Studio:**
1. Скачайте https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
2. Распакуйте и положите папку как `app/src/main/assets/model-ru` (внутри должны быть `am`, `conf`, `graph`, `ivector`).
3. Откройте проект в Android Studio → Build → Build APK.

## Как работает
- Звук декодируется (MediaCodec) → Vosk даёт слова с таймкодами.
- Видео делится на клипы заданной длины, разрез подгоняется под паузу между словами.
- Media3 Transformer вырезает фрагмент, кадрирует 9:16 и вшивает субтитры по 3 слова.
- Готовые клипы сохраняются в галерею: Movies/ReelsCutter.

## Настройки в коде
- Размер субтитров: `SUBTITLE_SIZE_PX` в `ClipExporter.kt`
- Положение субтитров: `setBackgroundFrameAnchor(0f, -0.55f)` там же
- Слов в строке: `cur.size >= 3` в `Planner.kt`
